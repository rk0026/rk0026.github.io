# Portfolio layout

English at `/`, Traditional Chinese at `/zh/`; Astro static site on GitHub Pages. Geist typography; saved light/dark themes. Colour is palette A "deep navy" (owner choice, 2026-11-08), all in `src/styles/global.css` tokens: light = pale blue-grey ground `#eef3fb`, white cards, navy ink `#0b1a33`, accent `#2f6bff`; dark = navy ground `#0b1a33`, cards `#12264a`, ink `#e8eefb`, accent `#7fb2ff`. Selected states (nav, pickers, 3D module) use `--accent`/`--accent-ink`. The five discipline colours (orange, blue, lime, yellow, purple) stay as accents.

Layout follows the structure of codewithsadee/vcard-personal-portfolio, not its colours or assets. Desktop: 1200px maximum shell with a sticky 275px profile sidebar and a right content panel. Below 1000px the profile moves above the content; contact details collapse into a native details element. Below 640px navigation sits at the bottom with safe-area padding.

Base.astro owns the shell. Sidebar.astro owns the portrait, identity, separately labelled current job, public contact links and résumé download. TopBar.astro keeps locale, clock and theme controls plus page links. Footer.astro contains only image attribution and copyright. Home no longer repeats the profile or contact list. Wispo remains a separate page. All existing page routes and note categories remain.

Verification: build plus browser checks at 1440 and 390 pixels, both themes, contact expansion and horizontal overflow. No copied testimonials, skill percentages or invented claims.

`/` (`/zh/`) is the wide 3D landing (`views/Landing.astro`, Base `wide`, no sidebar): intro + module detail on the left, `SystemCore.astro` on the right: a core switch (blinking port grid) on a round base with five mini server racks (Interface, Services, Data & AI, Delivery, Operations), each carrying its discipline colour as a front stripe and signal pulse; the selected rack lifts, turns its colour and holds its lights steady. Module buttons and detail panels are plain DOM and work without WebGL; the scene mirrors the selection, pauses offscreen, and renders statically with reduced motion. The previous home lives at `/overview/` (`views/Home.astro`, nav "Overview / 概覽"). Back to home: nav "Home" or the sidebar portrait/name. `/landing/` redirects to `/`.
